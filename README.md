# Lewis Moten

[![Lewis Moten](./img/social-preview.jpg)](https://lewismoten.github.io)

**Senior front-end engineer | React, TypeScript, and applied AI**

I turn complex data and workflows into usable web applications. I've programmed professionally since 1997, and my recent work spans interactive front ends, small local AI models, browser tools, and the infrastructure that runs them. I have led development teams and brought development builds down from 20 minutes to 2.

I'm based in Front Royal, Virginia and interested in senior front-end engineering and AI application roles.
