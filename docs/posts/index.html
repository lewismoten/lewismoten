THE CHEZ: running the engine from npm in a separate project

November 8, 2026 · Project: Game-Maker: Sandbox Edition

THE CHEZ is a small Vite and TypeScript app that tests whether the Game-Maker Sandbox engine can be installed from npm and run in a project of its own. Its bundled sample game, The Stripe Hypothesis, is there to prove the integration: Doc Leo swears racing stripes make THE CHEZ faster, Teddy has doubts, and the speedometer gets the last word.

Version 0.2.0 now takes the engine, archive, and tools packages from npm. The game downloads as one ZIP and is unpacked by the archives package.

Falken-9: a whole AI-vs-AI game in just over a minute

November 2, 2026 · Project: Falken-9

Crystal Palace 9, my Commodore 64 tic-tac-toe game, now runs on Falken-9, a new model I trained for the C64's arithmetic and memory from the start. The whole 5,195-byte model stays in RAM, so a complete AI-vs-AI game takes just over a minute in an emulator. The earlier model took about 20 minutes.

The second picture is the tensor workflow: every decoded weight, from the board embeddings through attention, the router and the four experts. The research report probes the network with interventions and charts what it found.
