Password Generator

Random passwords by instant message

A Second Life gadget that makes random passwords and sends them to you by instant message, so channel scanners cannot pick them up.

Source

Executive summary · Technical overview

Executive summary

Why it exists

Chat in Second Life can be overheard by scripts listening on channels, so a password tool cannot simply say the password out loud.

Outcome

Each password is sent to you by instant message, so channel scanners cannot pick it up.

My role

Author.

Technical overview

How it works

A panel with checkboxes for lowercase, uppercase, hex, numbers and punctuation, a numeric up/down for the length (1 to 64 characters), and radio buttons to remove look-alike characters such as 0 and O. Presets: Default (8 lowercase characters, no look-alikes), Strong (12 characters of every kind) and Guid (32 hex characters).
